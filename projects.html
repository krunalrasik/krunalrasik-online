Flow - An Open Source Design System

Flow is an open-source design + frontend framework. Flow is intended to be the fastest way to go from UI prototype to implementation. Flow achieves this by focusing on reusable templates combined with a friendly design + frontend developer experience.

View on Figma community launch      Learn more launch


Flow is made for designers and developers speak the same language. It aligns them for faster implementation cycles, fewer iterations, and more time for refining and testing to maximize feature value.

Stance

Stance empowers auditors, security admins, compliance officers, DevOps engineers, and developers to effortlessly manage compliance frameworks, ensuring seamless integration with security and infrastructure models.



As a product designer for Stance, I led the design efforts to craft a solution that redefines how organizations approach compliance. From research and strategy to BPMN flows, user journeys, and prototyping, I meticulously shaped every aspect of the user experience.

I collaborated closely with product management and engineering leadership to create a solution tailored for auditors, security admins, compliance officers, DevOps engineers, and developers.

The following is an example of the major steps I followed to deliver a particular feature, where a Compliance Officer is ingesting a compliance policy document into their organization using Stance:


Step 1 Create BPMN flow in collaboration with product management.


Step 2 Develop user journey flow and validate it with the engineering lead.


Step 3 Design mockups and prototypes, and validate them with both product management and engineering teams.
